## 新增需求

### 需求：离线指标评估可复用检索能力
系统应暴露一条可复用检索路径，用于在不触发答案生成的情况下，为 query 召回 TopN 候选文档。

#### 场景：离线评估器召回候选文档
- **当** 检索指标评估器提交 `query_text` 和配置的 TopN 值时
- **则** 系统应从 RAG 检索层返回候选文档，而不生成聊天答案。

#### 场景：候选召回遵守租户范围
- **当** 评估器为某租户的检索日志召回候选文档时
- **则** 系统应只返回该租户可见的候选文档。

### 需求：检索候选标识一致性
系统应在离线候选召回结果中返回稳定的 document 或 chunk 标识，使候选文档能够与 `retrieval_log` 中的原始命中文档比较。

#### 场景：候选与原始命中比较
- **当** 评估器收到 TopN 候选和原始命中文档时
- **则** 系统应使用稳定标识进行比较，而不是仅比较文档文本。
