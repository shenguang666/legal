## 新增需求

### 需求：RAG 检索指标日汇总表
系统应为每个租户、指标日期和评估版本维护一条 RAG 检索指标日汇总记录。

#### 场景：为指标日期创建日汇总
- **当** 定时指标任务开始处理某个租户和指标日期，且当前评估版本没有汇总记录时
- **则** 系统创建一条日汇总记录，包含租户 ID、指标日期、评估版本、任务状态、消息计数、平均召回率、平均精确率和时间字段。

#### 场景：复用已有日汇总
- **当** 定时指标任务继续处理某个租户和指标日期，且当前评估版本已存在日汇总记录时
- **则** 系统复用该汇总记录，而不是创建重复记录。

### 需求：评估明细归属于日汇总
系统应将每条消息级 RAG 指标评估记录存储为关联日汇总的子记录。

#### 场景：持久化子评估记录
- **当** 某条检索日志按指标日期完成评估时
- **则** 评估明细记录应引用日汇总 ID，并保存 query、原始命中 chunk ID、判定相关 ID、漏召回相关 ID、TP、FN、FP、recall、precision、模型元数据、状态、解释和错误信息。

#### 场景：按汇总查询明细
- **当** 管理员打开某条日汇总的明细列表时
- **则** 系统只返回归属于该日汇总的子评估记录，并支持分页。

### 需求：检索日志具备指标扫描状态
系统应在每条 `retrieval_log` 行上追踪 RAG 指标扫描进度。

#### 场景：标记检索日志完成
- **当** 指标任务完成某条检索日志的评估或过滤时
- **则** 系统更新该检索日志的终态指标扫描状态、扫描时间和关联日汇总标识。

#### 场景：重试失败检索日志
- **当** 某条检索日志为失败的指标扫描状态，且任务重试相同指标日期时
- **则** 系统可按配置的重试策略重试该日志，并根据新结果更新状态。

### 需求：指标状态使用枚举语义
系统应使用 Java 枚举类和已文档化的数据库字段值表示指标扫描、日汇总和评估状态。

#### 场景：存储枚举状态值
- **当** 系统持久化指标状态时
- **则** 应存储对应 Java 枚举定义的值，并在数据库字段注释中说明。

#### 场景：服务逻辑拒绝未知状态
- **当** 服务代码映射到一个未在对应枚举中定义的持久化状态值时
- **则** 系统应将其视为非法状态并安全失败，而不是静默按成功处理。

### 需求：定时任务覆盖所有符合条件的 RAG 消息
系统应处理指标日期内所有符合条件的 RAG 检索日志，不应强制设置每日最大样本数。

#### 场景：多批次处理所有符合条件的消息
- **当** 某个指标日期包含的符合条件检索日志数量超过单次任务批大小时
- **则** 后续低峰定时任务应继续处理剩余日志，直到所有符合条件日志都进入终态扫描状态。

#### 场景：过滤消息不参与评估但参与计数
- **当** 某条检索日志 query 命中配置的低质量 query 过滤规则时
- **则** 系统应将其标记为已过滤或已跳过，不进行 LLM 评估，并计入日过滤/跳过计数。

### 需求：低峰定时执行
系统默认应在配置的低峰窗口内每 5 分钟运行一次自动 RAG 指标任务。

#### 场景：默认低峰调度
- **当** 使用默认配置时
- **则** 指标 Worker 应按等价于服务器时间 02:00 到 05:59 每 5 分钟一次的 Cron 表达式运行，除非任务被禁用。

#### 场景：手动运行指定指标日期
- **当** 管理员手动触发某个指定日期的指标任务时
- **则** 系统应处理该请求指定的指标日期，而不受默认调度日期偏移影响。

### 需求：日聚合 API 使用汇总记录
系统应基于日汇总记录计算看板聚合指标，而不是每次请求都扫描所有子评估行。

#### 场景：日期范围汇总查询
- **当** 管理员请求某日期范围内的 RAG 指标时
- **则** API 应从匹配的日汇总记录中返回 RAG 消息总数、有效消息数、过滤数、成功数、失败数、跳过数、平均召回率、平均精确率和日趋势点。

#### 场景：空日期范围
- **当** 请求日期范围内不存在日汇总记录时
- **则** API 应返回零值计数和空趋势列表，不报错。

### 需求：ECharts 趋势可视化
RAG 指标看板应使用 ECharts 趋势图展示每日 recall、precision、RAG 消息数和有效消息数。

#### 场景：渲染趋势图
- **当** 前端从 summary API 收到日趋势点时
- **则** 应使用 ECharts 渲染 recall、precision 趋势和消息量趋势。

#### 场景：选择日汇总查看明细
- **当** 管理员在看板上选择某个日期或日汇总行时
- **则** 前端应加载对应的子评估明细，并展示消息级结果。
